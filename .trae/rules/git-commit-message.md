# Git 提交信息规范

## 格式

```
YYYY/MM/DD: {变更内容}
```

## 示例

```
2026/05/02: 按钮组件样式升级与新增取消类型
2026/05/01: 新增 letter-spacing 设计令牌
2026/04/30: 修复 ComponentVariant 文件名大小写问题
```

## 规则

1. **日期格式**：使用 `YYYY/MM/DD` 格式，如 `2026/05/02`
2. **分隔符**：日期与内容之间使用冒号 `:` 分隔
3. **语言**：使用简体中文描述变更内容
4. **简洁性**：变更内容应简洁明了，一行概括
5. **范围标注**：如涉及特定模块，可使用 `[{模块名}]` 标注

## 多项变更

如有多个独立变更，每个变更单独一行：

```
2026/05/02:
- [组件] 按钮组件新增 activeEffect 属性
- [样式] 统一颜色层级命名规范
- [文档] 更新 Storybook stories
```

## 提交类型前缀（可选）

- `[新增]` - 新功能
- `[优化]` - 改进现有功能
- `[修复]` - Bug 修复
- `[重构]` - 代码重构
- `[文档]` - 文档更新
- `[样式]` - 样式变更
- `[类型]` - 类型定义变更
